# 数模评委 Skill v2.5 完整设计（终版，整合全部修正）

> 2026-08-13 | 整合：三轮外部打回教训（MCM 66-70、华数杯 56-65）+ 六机制 + 冷启动参照系 + 三评架构 + 推演先行 + 数据血缘
> 设计哲学一句话：**先读懂论文（推演），再有靶子地查（搜索），最后才谈分数**

## 一、设计哲学（6 条）

1. **推演先行**：评审的第一动作是顺着论文思路重建论证链，而不是按清单扫描。没有推演的搜索是无靶子的——论证链中段的推理断裂只有推演才能看见。
2. **语义完成度**：检查"题目要求是否被完成"（要求单元→产出物），而非"字面是否对"（词频/同值/公式计数）。词频出现≠完成。
3. **隔离多视角**：评审一律新开零上下文子代理；三评（GLM+Kimi+新开 DeepSeek）——新开的 DeepSeek 与撰写论文的 DeepSeek 不是同一个实例，隔离机制天然允许它做评审。
4. **冷启动完备**：评审锚 = 官方规范 + 历史水平标尺 + 领域知识 + 方法论标准（T1-T4 赛前本地化），不依赖同题信息（T5 竞赛窗口内权重=0）。16 条教训无一需要联网才能发现。
5. **确定性优先**：脚本能查的绝不靠 LLM；审计穷尽执行（fail-fast 仅限修订-替换校验）；段1 单向棘轮（段2 不可撤销段1 finding）。
6. **可校准**：每轮外部打回二分闭环回流（覆盖缺口→补规则；尺度偏差→修锚点），回放测试防退化。

## 二、完整流程（六阶段）

```
阶段 0 输入准备
  题目官方文件解析 → 要求单元提取（实体+量化指标+限定词+案例名单）
  题型判定（预测/优化/评价/机理/统计）→ 加载题型交付物清单
  参照系加载：T1 官方规范 / T2 历史分位 / T4 方法论标准（本地）；T3 领域知识（联网增强）
  ↓
阶段 1 段1 确定性审计（脚本，穷尽执行，finding 独立记录）
  1.1 数字血缘：论文每个数字 → 结果文件 → 脚本 → 原始数据，三级回溯
  1.2 版面门禁：编号公式计数 / 图型-题型匹配 / 表序递增 / 文本卫生（双负号/占位符/乱码）
  1.3 要求-回应语义矩阵（M1）：要求单元 → 章节+产出物类型，词频不计入
  1.4 题型交付物清单（M2）：预测题 MAPE+pred-vs-actual；优化题 Pareto+权重对比
  1.5 引用链+统计三要素（M4）：[n]↔文献交叉验证 / SE+p+CI / DOI 抽查
  1.6 数据源三态核查（M6）：PASS / FAIL / UNVERIFIED，降级链，无静默绿
  ↓ 单向棘轮
阶段 2 推演（三个隔离子代理各自独立执行，先于一切搜索）
  2.1 论证链重建：每个结论 → 前提 → 推理步骤（claim-evidence-reasoning）
  2.2 疑点标记：推理薄弱的"承重墙"环节清单
  2.3 逻辑冲突检查：
      因果方向冲突（摘要"碳价主导"vs 正文"容量驱动"）
      口径冲突（同指标两处算法不同 → scope 四元组比对）
      论证冲突（推荐理由与自身数据相反 → 论证依赖图）
      循环论证（论证链中的环：A 依赖 H，H 又依赖 A）
  ↓ 推演产出 = 论证链 + 疑点清单
阶段 3 定向搜索（对疑点逐个验证，有靶子的搜索）
  3.1 计算复现：疑点涉及的数字链全链条重跑（原始数据→中间结果→论文数字）
  3.2 数据血缘回溯 + 错误传播反查：发现错误中间值 → 依赖图反查全部下游引用 → 批量标记复核
  3.3 定性词-证据绑定（M3）：每个定性词绑证据定位；与数据形状矛盾 = HARD FAIL
  3.4 联网定向核对：仅对疑点相关的口径/数据源定向检索，非漫扫
  3.5 三态结论：每个疑点 证实 / 证伪 / 存疑
  ↓ 疑点验证结果回推演，修正理解
阶段 4 三评与仲裁（M5）
  三子代理各自七维评分（相对锚点先于绝对分，摘要盲评，维度乱序）
  总分差>5 或维度差>2 → 仲裁（多数/中位数）
  ↓
阶段 5 输出与闭环
  输出：分数区间 + 相对分位 + 修订单（Top-12，severity/evidence/fix）
  修订回路：修订单回喂 → 全量重跑段1+段2（禁止针对性复查）→ Δ<1 或 2 轮无 critical 停止
  校准回路：外部打回 → 二分闭环 → 回归用例入库 → 回放重测（16 教训命中≥14）
  漂移监控：修订前后分数差入库；两轮漂移>3 分只报区间不报点分
```

## 三、核心组件

### 3.1 论证链重建（阶段 2 的核心动作）
子代理 prompt 强制输出：每章的 claim 清单 → 每个 claim 的证据指针（图/表/数字编号）→ 推理步骤（从证据到 claim 的推断逻辑）。评分资格前置：无论证链重建 = 无权打分。这使"证据在但推不出结论"（消融证伪却照吹）成为可判定的缺陷，而非靠评审直觉。

### 3.2 依赖图底座（贯穿段1.1/段2/段3，即原 M7）
两类依赖图共享同一数据结构：
- **论证依赖图**：结论单元 → 依赖的假设/数据/前序结论。用途：循环论证检测、矛盾依赖检测。
- **数据依赖图**：论文数字 → 中间结果文件 → 脚本步骤 → 原始数据。用途：血缘回溯、错误传播反查（错误中间值一经发现，下游引用批量标记复核，切断错误复用）。
这是逻辑检查与计算正确性的共同底座。

### 3.3 隔离三评
子代理 A=GLM、B=Kimi、C=DeepSeek（新开实例）。三者错误独立（异模型），分差仲裁。机器强制摘要盲评+维度乱序（不依赖 LLM 自觉）。

### 3.4 冷启动参照系
T1 官方规范 / T2 历史标尺 / T4 方法论标准：赛前全量本地化；T3 领域知识：联网增强+降级链；T5 同题信息：竞赛窗口内权重=0（时钟硬门控），命中即隔离打标，永不作评分依据。

## 五、验收标准（Kimi 8 条）

1. 离线回放完备性：断网跑两篇已打回论文，16 条教训命中 ≥14，HARD FAIL 100% 离线可命中
2. 穷尽无短路：注入 ≥5 并发缺陷 → finding ≥ 注入数
3. 单向棘轮断言：段2 无任何段1 HARD FAIL 被撤销
4. 三评效度：437 篇基准上分差>5 比例 ≤ 阈值，仲裁正确激活
5. 污染免疫：伪造"官方思路"注入 → 评分偏移 ≤ 噪声阈值
6. 降级诚实：kill-network 无静默绿，跳过项全列+置信度降档
7. 输出协议合规：区间+分位+修订单三段；漂移>3 无点分
8. 校准闭环时效：打回→映射+用例→回放通过，一个迭代周期

## 六、已知边界（诚实声明）

- M1-M3 规则从 16 条已知教训抽象——第 17 类未知缺陷仍可能穿检；对策：规则在语义层级抽象 + hold-out 泛化测试 + 推演/隔离三评兜底未知。
- 依赖图的反查能力受图构建完整性限制：论文数字若未注册进 registry，血缘断链——数字索引双向覆盖是依赖图的前置。
- 三评的"评对"上限仍受 LLM 与人类一致率（72-85%，prometheus 实证）约束；确定性层承诺零漏检，论证质量判断承诺"可审计的推理"，不承诺与人类评委完全一致。
