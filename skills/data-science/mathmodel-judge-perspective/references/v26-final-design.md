# 数模评委 Skill v2.6 详细设计文档

> 2026-08-14 | 输入：外部真人评审 80 分打回（17 条问题，AI 四轮仅抓 26%）+ 混合管线反思（GLM 结构分析/Kimi 校准分析/DeepSeek 汇总）
> 核心事实：GLM 92 / Kimi 83 / DS 78 vs 真人真值 80±4——AI 评审的失分不是"看不清"而是"不去看"（线性阅读 vs 真人全局 spot-check）

## 一、版本演化动机

| 版本 | 解决 | 被证明不足 |
|------|------|-----------|
| v2.2 | 数字索引/七维评分 | 完成度缺陷（漏答）穿检 |
| v2.4 | 隔离评审+联网+公式门禁 | 语义层缺陷（名实不符）穿检 |
| v2.5 | 推演先行+依赖图+视觉层 | 跨模态数字打架 5/5 漏、方法学名实 4/7 漏、文献 0 覆盖 |
| **v2.6** | 四方 diff+名实审查+扣分制评分+真人常模 | —— |

**v2.6 设计原则**：把真人评委的"随手抽查"程序化（P0），把"名实相符"的语义推理强制化（P1），把"印象式打分"改为"清单式扣分"（P2），把领域常模注入评审（P3）。

## 二、新增机制详细设计

### D 组：确定性检查扩展（段1 审计新增 3 项，全部程序化）

**D1 跨模态数字一致性四方 diff（P0-1）**
- 输入：论文 PDF 全文本 + 全部表格文本 + 全部图内文字（OCR/视觉提取）+ 摘要文本
- 机制：提取四方所有"指标名+数值"对（如"均值利用率 67.4%"），构建 (指标, 位置, 值) 三元组 → 同名指标跨位置 diff → 不一致即 finding（severity 按差值等级）
- 触发：必跑（每次评审）
- 验收：A 类 5 条（表3 vs 正文、§5.2 vs 表6、表4 vs 摘要、56.5/56.1、137.2/137.1）全部命中，零漏检
- 关键教训：多轮迭代论文必现"新旧结果拼贴"，只有全局 diff 抓得到，局部阅读抓不到

**D2 约束完备性枚举（P0-2）**
- 输入：题面+附件 1 的约束全集（硬编码清单，按题型模板）+ 论文公式/求解器描述
- 机制：约束类型逐一映射（题面约束 → 论文公式编号 → 实现位置），缺映射 = "可行性声明失实" finding
- 华数杯 C 的约束全集：GPU 容量/IT 功率/设施功率/网络时延/完工时限/MaxGridImport/MaxGridExport/SOC 上下限/SellLimit/充放电互斥/终值约束
- 验收：MaxGridImport 类漏建模 100% 命中

**D3 图内文字-题注一致性（P0-3）**
- 视觉层新增检查项：图内标题/自编号/轴标签 与 论文题注编号、正文引用编号 三方比对
- 验收：图内"图5"vs 题注"图1"类 100% 命中

### E 组：名实相符审查（段2 推演时强制执行，4 项）

**E1 目标-机制映射审查（P1-4）**
- 推演 prompt 强制项：每个题面目标 → 必须定位"在模型的哪一步生效"（公式/算法步骤/结算端）
- 判定规则：目标无机制定位 = 名实不符（major）；声称"四目标"实为三项入评分 = 机制级缺位
- 教训：v2.5 抓到"公式-实现断层"但修复方向错误（删项 vs 论证合理性）——E1 要求评审方输出"缺位判定"而非"一致性判定"

**E2 对照公平性审查（P1-5）**
- 消融/对照实验的对照组必须通过公平性三问：①对照组 isolate 了声称的机制吗？②对照组只差一个变量吗？③对照组是"公平的强对照"吗（如"本地优先+统一结算"vs 原始基准）？
- 归因声明的强度必须与对照公平性匹配：不公平对照 → "改善归因夸大" finding

**E3 基线公允性审查（P1-6）**
- 领域基线先验清单（按题型模板）：预测题必须含季节朴素基线（滞后 24h/168h）；调度题必须含 EDF 本地优先基线
- 基线强度不足 → "挑软柿子" finding（提升幅度声明相应打折）

**E4 文献评审项（P1-7，全新）**
- 检查：文献数量（≥8 为常模）、领域覆盖（题目核心方法是否有对应文献）、正文 [n] 引用与参考文献条目对齐、格式规范（书籍/期刊/网络三式）
- 输出：文献维度 finding（数量不足/领域缺失/格式错误）

### F 组：评分引擎重构（段4 三评评分方式整体替换）

**F1 扣分制替代印象式打分（P2-8）**
- 每维从基准分（摘要 13/建模 22/完整性 17/验证 13/写作 8.5/图表 8.5/创新 3.5，合计 85.5）起，按 issue 清单逐项扣分
- 扣分必须在 issue 清单落地（每条扣分引 finding 编号），无清单的扣分无效
- 根因：GLM 的 +12 偏差来自"整体印象+善意阅读"，扣分制强制其逐项过 issue

**F2 严重度×可修复性二维扣分矩阵（P2-10）**
| | 易修复（文字/数字） | 难修复（需重算/重构） |
|---|---|---|
| 致命（数字打架/约束缺失） | −2~−3 | −4~−5 |
| 严重（名实不符/归因夸大） | −2 | −3 |
| 中（口径混用/基线弱） | −1 | −2 |
| 轻（写作/排版） | −0.5 | −1 |

**F3 真人常模分位映射（P2-9）**
- 历届同赛题真人评分建立分位数常模（获奖线 ≈80±4、一等 ≈85+）
- AI 原始分 → 常模分位映射输出最终区间（消除模型锚点漂移：GLM+12 与 DS−2 的 14 分差即锚点不一致）

**F4 证据锚定强制令（P2-11）**
- 每个维度的评分必须引用具体表号/页码/数字；无法落地引用的维度判无效并降档复核

### G 组：深度与写作（段2/段5 轻量检查）

**G1 深度常模**：页数（12 页偏薄）、权重选取依据、算法复杂度分析、运行环境对比
**G2 摘要结构**：分小段（四问分段）、关键词 ≤5 个、摘要内引用标记规范
**G3 图表可读性**：甘特图信息密度、色块可辨性、图与叙述的一致性

## 五、冲突消解决议（混合管线审查：GLM 9 条 + Kimi 4 条 → 合并 8 项决议）

> 审查结论：v2.6 初版存在 2 critical + 4 major + 6 minor 冲突，8 项决议后自洽。

### 决议 1（critical）：评分引擎重定义——"扣分记录制"替代"基准分扣分制"
- 冲突：F1 的 85.5 基准分与"相对锚点先于绝对分"哲学矛盾（GLM）；85.5 与满分 100 的差值 14.5 无 finding 支撑，违反 F1 自己的"无清单扣分无效"，且 85.5 恰卡一等线 85+，有预写常模结论之嫌（Kimi）
- **决议**：F1 改为**满分 100 起扣**，输出的是"扣分记录"（finding 编号→扣分额）而非直接分数；最终分 = F3 分位映射（100−Σ扣分 → 常模分位 → 绝对分）。评分顺序固定：**先扣分（F1/F2）→ 后映射（F3）→ F4 证据锚定全程审计**。相对锚点的地位恢复：映射步骤即"先分位后绝对分"

### 决议 2（critical）：F1/F3 执行顺序显式化
- 冲突：先扣分再映射 vs 先映射再扣分未定义（GLM）
- **决议**：固定顺序为 扣分→映射。原因：扣分是对"缺陷"的加和（缺陷与常模无关），映射是对"分数含义"的校准（分数与竞赛水位有关）——两者作用域不同，顺序天然确定

### 决议 3（major）：图内文字提取前置到段 1
- 冲突：D1 需要图内文字（OCR）但视觉评审在段 1.5（GLM）
- **决议**：段 1 审计内嵌**程序化图内文字提取**（OCR 或 matplotlib 源码扫描——优先源码扫描，图像 OCR 兜底），视觉评审段 1.5 只做像素级主观项。D1 输入自给，不依赖段 1.5

### 决议 4（major）：D1 差值 → F2 严重度映射规则
- 冲突：D1 说"severity 按差值等级"但映射未定义（GLM）
- **决议**：数字差>5% 或单位量级错 = 致命；1–5% = 严重；<1% = 轻；同数字多次矛盾累加升级

### 决议 5（major）：E 组判定 → F2 扣分映射
- 冲突：E1 名实不符如何扣分未定义（GLM）
- **决议**：E1 缺位判定 = 严重×难修 = −3；E2 对照不公平 = 严重×易修 = −2；E3 基线弱 = 中×易修 = −1；E4 文献不足 = 轻 = −0.5~−1

### 决议 6（major）：D/E 判定权威——事实层优先，棘轮语义修订
- 冲突：D2（二值枚举）与 E1（灰度判定）结论矛盾时优先级未定义（Kimi）
- **决议**：D 组事实层 finding 不可被 E 组推翻（棘轮）；E 组可对同一问题输出"语义补充"（如 D2 判"约束未建模"=事实，E1 可补充"该约束在题面权重低"=语义），补充不改事实；棘轮语义修订为**"净确认 finding 只增不减"**（仲裁确认误报可标记 retracted 并回溯扣分，原始记录保留）

### 决议 7（minor）：边界澄清三处
- E1（目标-机制映射）vs M3（断言-证据绑定）：E1 查目标层、M3 查断言层，判定对象不同粒度
- D2（约束枚举）vs M1（要求-回应矩阵）：D2 是 M1 的程序化前置（先枚举约束完备性，再做语义矩阵）
- E 组时序：在论证链重建**完成后**的复核阶段做（先理解模型再查名实），非推演早期
- G 组结果纳入 F1 扣分项（深度不足 −1、摘要结构 −0.5、图可读性 −0.5）

### 决议 8（minor）：时间预算与常模冷启动
- 时间预算：E1-E4 使推演时长增加，40 分钟预算重测；超时则 E 组降级为"仅 E1/E2 强制、E3/E4 抽检"
- F3 冷启动：无历届真人数据时，用公开获奖名单档位近似（一等≈85+、二等≈75-84、三等≈65-74），随评审数据积累切换为实测量化分位

1. D1 四方 diff 依赖图内文字提取质量（视觉 OCR 误差 → 误报），容差阈值需按图像类型校准
2. F3 常模需要历届真人评分数据积累，冷启动时用公开获奖名单档位近似
3. E1 名实审查的判定边界（"解耦合理性"vs"目标缺位"）存在灰度，评审方输出判定+理由，不强行二值化
4. 扣分制的基线分设定本身需要校准（用回放测试迭代）
5. 本质限制不变：第 17 类未知缺陷仍靠隔离评审+校准回路吸收，v2.6 只是把"已知缺陷空间"从 17 条扩到更全
