# 数模评委评价 Skill — 站在评委立场反向审视论文

> 版本 v2.5（六阶段架构：审计→推演→定向搜索→三评→输出→校准）· 实证来源：
> 437 篇美赛 O 奖论文全量精读 + 55 题全量独立求解校准 + 两轮外部评审打回教训（MCM 66-70 / 华数杯 56-65）+ 评委机制调研（prometheus-eval / Linference / cumcm）
> 设计文档：references/v25-final-design.md（完整设计含验收标准与已知边界）

## 核心原则（6 条）

1. **推演先行**：评审第一动作是顺着论文思路重建论证链，而非按清单扫描——没有推演的搜索无靶子，论证链中段的推理断裂只有推演能看见
2. **语义完成度**：查"题目要求是否被完成"（要求单元→产出物映射），不是"字面是否对"——词频出现≠完成
3. **隔离多视角**：评审一律新开零上下文子代理；三评（GLM + Kimi + 新开 DeepSeek）——新开的 DeepSeek 与撰写论文的 DeepSeek 不是同一个实例
4. **冷启动完备**：评审锚 = T1 官方规范 + T2 历史标尺 + T4 方法论标准（赛前本地化）+ T3 领域知识（联网增强）；T5 同题信息竞赛窗口内权重=0。16 条打回教训无一需要联网才能发现
5. **确定性优先**：脚本能查的绝不靠 LLM；审计穷尽执行（fail-fast 仅限修订-替换校验）；段1 单向棘轮（段2 不可撤销段1 finding）
6. **可校准**：每轮外部打回二分闭环回流（覆盖缺口→补规则 / 尺度偏差→修锚点），回放测试防退化

## 评审总流程（六阶段）

```
阶段 0 输入准备
  题目官方文件解析 → 要求单元提取（实体+量化指标+限定词+案例名单）
  题型判定（预测/优化/评价/机理/统计）→ 加载题型交付物清单
  参照系加载：T1/T2/T4 本地；T3 联网增强（失败降级 UNVERIFIED）
  ↓
阶段 1 段1 确定性审计（脚本，穷尽执行，finding 独立记录）——见 §二
  ↓ 单向棘轮
阶段 2 推演（三个隔离子代理各自独立，先于一切搜索）——见 §三
  ↓ 产出 = 论证链 + 疑点清单（承重墙标记）
阶段 3 定向搜索（对疑点逐个验证，有靶子的搜索）——见 §四
  ↓ 疑点三态结论（证实/证伪/存疑）回推演，修正理解
阶段 4 三评与仲裁（M5）——见 §五
  ↓
阶段 5 输出与闭环：分数区间+相对分位+修订单 → 修订回路全量重跑 → 校准回路
```

**为什么审计在推演前面**：①事实先进场，修辞不污染判断；②推演引用的证据指针必须先经真值校验；③脚本便宜零误报，LLM 预算全留给推理；④单向棘轮的工程要求（段2 无权推翻段1 的客观 finding）。

## §一 推演：论证链重建（段2 第一动作，先于一切搜索）

**评分资格前置**：子代理未输出论证链重建 = 无权打分。

**论证链重建格式**（子代理 prompt 强制）：
```json
{"claims": [
  {"id": "C-1", "claim": "迁移决策由碳价驱动",
   "evidence": ["表5 迁移率 47.3%→49.6%", "§6.1 第二段"],
   "reasoning": "从证据到结论的推断逻辑（逐句）",
   "weak_link": "evidence 是否足以推出 claim：sufficient/insufficient/contradictory"}
]}
```
- weak_link = insufficient：证据在但推不出结论（如消融表显示对照占优、结论却称模型有效）
- weak_link = contradictory：证据与结论方向相反（如宣称"平台"实为单调下降）

**逻辑冲突四查**（推演中逐项过）：
| 类型 | 例子 | 检查 |
|------|------|------|
| 因果方向冲突 | 摘要"碳价主导" vs 正文"容量驱动" | HARD FAIL |
| 口径冲突 | 同指标两处算法不同 | registry scope 四元组比对 |
| 论证冲突 | 推荐理由与自身数据相反 | 论证依赖图 |
| 循环论证 | A 依赖假设 H，H 又依赖 A | 依赖图找环 |

## §二 确定性审计（段1，脚本穷尽执行）

六项检查，全部程序可判定、零误报，finding 独立记录互不遮蔽：
1. **数字血缘双向覆盖**：论文每个数字 → 结果文件 → 脚本 → 原始数据三级回溯；registry 每个谓词 ∈ 核对清单——清单外即盲区
2. **版面门禁**：编号公式计数（模型建立每问核心模型 ≥1 条编号公式，否则该维度封顶 40%）/ 图型-题型匹配 / 表编号递增（表 3 不能排在表 1 前）/ 文本卫生（双负号"−-"、占位符 Page X/TODO、乱码）
3. **要求-回应语义矩阵**：题目要求单元 → 章节+产出物类型（公式/表/图/数字）；词频出现不计入，无产出物 = 漏答
4. **题型交付物清单**：预测题强制 MAPE/RMSE + pred-vs-actual 图 + 残差诊断；优化题强制 Pareto 前沿 + 权重方案对比；评价题强制指标体系 + 权重敏感性
5. **引用链+统计三要素**：[n]↔参考文献交叉验证（无悬空引用）；回归/统计表强制 SE + p + CI；DOI 抽查
6. **数据源三态核查**：PASS / FAIL / UNVERIFIED（超时降级链：在线→本地缓存→"未核查"标注），禁止静默通过

**审计顺序内的两个纪律**：① fail-fast 只允许用于修订-替换校验（n_replace==0 立即报错），审计侧永远穷尽执行；② 每项 finding 必须带文件定位（节/表/图/行）。

## §三 定向搜索：计算正确性与错误传播反查（段3）

对推演产出的疑点清单逐个验证（不是漫扫）：
1. **计算复现**：疑点涉及的数字链全链条重跑（原始数据→中间结果→论文数字），对照论文数值
2. **数据血缘回溯**：数字按依赖图回溯到源头，检查哪一步算错
3. **错误传播反查**（核心）：发现错误中间值 → **依赖图反查全部下游引用** → 批量标记待复核——切断错误数据复用，不靠人工挨个找
4. **定性词-证据绑定**：平台/饱和/解耦/主导/显著/鲁棒等定性词必须绑证据定位；无证据 = major；与数据形状矛盾 = HARD FAIL
5. **联网定向核对**：仅对疑点相关口径/数据源定向检索（非漫扫）；凡联网结果带来源 URL+时间戳+层级标注
6. 每个疑点输出三态结论：证实 / 证伪 / 存疑

**依赖图底座**（论证依赖图 + 数据依赖图共用结构）：
- 论证依赖图：结论单元 → 依赖的假设/数据/前序结论（查循环论证、矛盾依赖）
- 数据依赖图：论文数字 → 中间结果文件 → 脚本步骤 → 原始数据（血缘回溯、错误传播反查）
- 前置：数字必须注册（§二 第 1 项双向覆盖是依赖图的地基）

## §四 三评与仲裁（隔离评审）

- **评审一律 delegate_task 新开子代理**：只传论文 PDF 绝对路径 + 题目原文路径 + 评分标准 + 修订单格式；不传任何撰写过程信息（设计决策/踩坑/权衡/prompt/结果文件路径）
- **三评**：A=GLM、B=Kimi、C=DeepSeek（新开实例）——异模型错误独立，防"同模型双实例假独立"
- 子代理必须亲自读 PDF 原件（pymupdf 版面核查），以自己读取的官方题目文件为准
- **机器强制**（不依赖 LLM 自觉）：摘要盲评（先评摘要再读全文）、维度乱序、相对锚点先于绝对分输出
- **仲裁**：总分差 >5 或任一维度差 >2 → 多数/中位数裁决
- **漂移铁律**：两轮自评分数漂移 >3 分 → 禁止对外报告点分，只报区间

## §五 评分体系（七维 + 相对锚点，437 篇实证校准）

| 维度 | 权重 | 评委在问什么 |
|------|:--:|------------|
| 摘要与概述 | 15% | 一页内说清：问题+方法+关键数值+意义？必须有具体数字 |
| 建模合理性与创新 | 25% | 模型贴题？假设有论证？方法选择有理由？编号公式完整？ |
| 问题解决完整性 | 20% | 每个子问题被完整回答？要求单元→产出物一一对应？ |
| 分析与验证深度 | 15% | 基线对比 + 灵敏度量化 + 不确定性区间？ |
| 写作与表达 | 10% | 清晰简洁、逻辑连贯？ |
| 图表质量 | 10% | 专业、信息量大、标题即结论、被正文引用？ |
| 创新与洞察 | 5% | 原创洞察 + 可执行建议？ |

- **判定档位**：90+ O / 75-89 M / 60-74 H / <60 S
- **相对锚点先于绝对分**：评审结论必须含"该维度在 437 篇基准的分位"（如验证深度前 20%）
- **校准口径**：评审前读 3 篇锚定论文（5.5/7.8/9.2 档各一篇）；7.5=省一以上，5.0=基本完成
- **评分偏差自检五条**：宽容/晕轮/近因/创新崇拜/图表偏见——报告自陈触发与否
- **逐档行为锚点**：每维按可观察行为五档递进（consistently/typically/intermittently/neglects/absent）打分，禁止形容词脑补

## §六 HARD FAIL 总表（任一命中直接降档）

1. 数据/结果/引用编造（含错误数据复用未阻断）
2. 摘要与正文关键数字不一致（21.9/22.2 并存类）
3. 摘要与正文因果结论相反（"碳价主导" vs "容量驱动"并存）
4. 有子问题未回答 / 题目点名对象缺失（对照表从题目原文逐句生成，禁止解题者自己的概括）
5. 要求单元零产出物（点名指标被提及但无表/图/数字——"峰值净购电"有词无数）
6. **模型建立章节零编号公式**（v2.4：9 页零公式 = 模型建立空白）
7. **自毁性证据未回应**（v2.4：消融显示核心模型被平凡变体 Pareto 占优且未答"买到了什么"）
8. **定性宣称与数据形状矛盾**（"平台"实为单调、"解耦"实为显著变化）
9. 公式数学错误（维度/定义域）
10. 图表与正文结论矛盾 / 图表无编号无引用
11. 全文仅 1 个模型且无基线对照（多模型互证 100% 铁律）
12. 摘要零数字 / 灵敏度只声明不量化（无参数-指标表）
13. 不确定性传播断裂（自证接近噪声仍用点估计当事实且无区间传播）
14. 推荐/结论与论文自身机制矛盾
15. "快照冒充全程"（点名案例只给单时点而非题目要求的全程）
16. 稻草人基线（核心估计的基线是无意义下限而未与合理先验对比）
17. 引用断裂 / 占位符残留（Page X、TODO、页眉残留）

## §七 冷启动参照系（刚开赛：无同题论文、无获奖范文、无标准答案）

| 层 | 内容 | 用途 | 刚开赛可用 |
|----|------|------|:---:|
| T1 官方规范 | 题目原文/格式规范/AI 章程 | 合规基准 | 永远（本地） |
| T2 历史水平标尺 | 往年同题型 O/M 奖论文（437 篇本地 + 线上延伸） | "做到什么程度算好"的评分锚 | 永远 |
| T3 领域知识 | 题目背景行业资料（碳强度/电价机制等） | "数字是否离谱、口径是否行业标准" | 永远（联网增强，失败降级 UNVERIFIED） |
| T4 方法论标准 | 预测/优化/储能教科书级做法与评价指标 | "方法是否常规、指标是否用对" | 永远（本地） |
| T5 同题信息 | 赛后才有的思路/论文/获奖名单 | 仅作水平标尺参考 | 赛程中无（窗口内权重=0，时钟硬门控非 LLM 裁量，命中即隔离打标，永不作评分依据） |

**铁律**：①评审的锚 = 题目要求 + 领域标准 + 历史水平，不依赖同题信息；②同题信息永不作正确答案来源（防带偏"官方思路"污染），只作他人做法分布参考且标注来源时效。

## §八 输出协议与校准回路

**输出三段结构**：分数区间 + 相对分位（先于绝对分）+ 修订单（Top-12）
**修订单格式**：
```json
{"items": [{"severity": "critical|major|minor",
   "issue": "一句话问题", "evidence": "论文位置+实锤或判断",
   "fix": "可执行修复动作", "section": "受影响章节",
   "acceptance_check": "修复后如何验证"}]}
```
按 severity 排序；每轮必出修订单，禁止只给总分；无证据定位的批评视为无效批评。

**修订回路**：修订单回喂撰写端 → **全量重跑段1+段2**（禁止针对性复查——针对性复查=刷分）→ 修订前后分数差入漂移监控。

**量化收敛**：修订单清空后复评，均分变化 <1 或连续 2 轮无 critical → 停止迭代强制交付。

**校准回路**（每轮外部打回必走）：
```
外部打回 → 二分闭环：覆盖缺口（该查没查→补规则+教训-机制映射）vs 尺度偏差（查了给宽→修锚点+偏差修正）
→ 回归用例入库 → 回放重测（16 条教训命中 ≥14 放行）
```

**验收标准（Kimi 8 条）**：①离线回放完备（断网跑已打回论文，教训命中≥14，HARD FAIL 100% 离线可命中）②穷尽无短路（注入≥5并发缺陷→finding≥注入数）③单向棘轮（段2 无撤销段1）④三评效度（437 基准分差>5 比例≤阈值）⑤污染免疫（伪造"官方思路"→评分偏移≤噪声）⑥降级诚实（kill-network 无静默绿）⑦输出协议合规 ⑧校准闭环时效（一个迭代周期）。

## §九 实证资产摘要（v2.0-2.4 沉淀）

- **官方一手**：2019 Triage 指南（7 档、初评两读、10-15 分钟/篇、60-80% 淘汰；五要素缺任一封顶；"fail to build Spread Model no higher than 2"）；2009 Judges' Commentary（摘要决定生死、摘要正文必须一致、灵敏度每年必谈、基线验证立即加分）
- **437 篇 O 奖精读**：18 组 287KB 结构化笔记；多模型互证与验证深度是 O 奖最大区分项
- **55 题实战校准**：平均 80.4（O×2/M×47/H×6）
- **评委心理**：先找硬伤再找亮点——消除硬伤比制造亮点更重要；喜欢"一眼看懂"的论文；讨厌"需要替他找答案"的论文
- **写作正面清单**：4 段式摘要（背景+方法+关键数字+意义）、变量符号表、方法选择理由（含淘汰方法）、每数值从 ≥3 维度讨论、图表标题写结论、三线表
- **写作负面清单**：编造数据=最低档；AI 修辞（"首先其次""显著提高"）；假设凭空（"假设正态"无理由）；图表沦为装饰

## §十 已知边界（诚实声明）

- 审计规则从 16 条已知教训抽象——**第 17 类未知缺陷仍可能穿检**；对策：规则语义层级抽象 + hold-out 泛化测试 + 推演/隔离三评兜底未知
- 依赖图反查受注册完整性限制（数字未注册→血缘断链）；数字索引双向覆盖是依赖图前置
- 三评"评对"上限受 LLM 与人类一致率（72-85%，prometheus 实证）约束：确定性层承诺零漏检，论证质量承诺"可审计的推理"，不承诺与人类评委完全一致
