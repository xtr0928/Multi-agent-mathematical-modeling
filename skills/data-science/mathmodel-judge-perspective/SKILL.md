# 数模评委 Skill v2.6（终版）

> 版本 v2.6-final · 2026-08-14
> 演化：437 篇正样本 → 两轮外部打回 → 隔离+联网 → 推演先行 → 四方 diff+名实审查+扣分记录制
> 设计来源：31 个开源项目机制级借鉴（写评分离/registry 三收敛/确定性断言/行级溯源）+ 四轮实战校准
> 冲突消解：混合管线审查 8 项决议（详见 references/v26-final-design.md）

## §零 核心原则（6 条）

1. **推演先行**：先重建论证链读懂论文，再有靶子地查——没有推演的搜索无靶子
2. **语义完成度**：查"要求是否被完成"（要求单元→产出物），不是"字面是否对"
3. **隔离多视角**：三评（GLM/Kimi/新开 DeepSeek）——评审实例与撰写实例完全分离
4. **冷启动完备**：参照系 T1-T5（官方规范/历史标尺/领域知识/方法论标准/同题信息），T1-T4 本地化，T5 竞赛窗口内权重 0
5. **确定性优先**：脚本能查的不靠 LLM；D 组事实层不可被 E 组推翻
6. **扣分记录制**：评分 = 满分 100 − Σ(issue 扣分) 的输出是扣分记录，最终分由常模分位映射给出

## §一 评审流程（六阶段）

```
0 输入准备：题目解析 → 要求单元提取 → 题型判定 → 约束全集枚举（D2 前置）→ 参照系加载
1 段1 确定性审计（脚本穷尽）：数字血缘 · 版面门禁 · M1/M2 · 引用链 · D1/D2/D3 → 单向棘轮
2 段2 推演（三隔离代理）：论证链重建（评分资格前置）→ 完成后复核：E1-E4 名实审查
3 段3 定向搜索：疑点验证 · 数据血缘回溯 · 错误传播反查 · M6 三态联网核对
4 段4 评分引擎：满分起扣（F1/F2）→ 常模分位映射（F3）→ 证据锚定审计（F4）→ 三评仲裁
5 输出与闭环：分数区间+分位+修订单 → 修订回路全量重跑 → 校准回路（打回二分闭环回流 D/E 规则）
```

## §二 段1 确定性审计（脚本穷尽执行）

**审计六项 + D 组三项**（每项 finding 必须带文件定位）：

1. **数字血缘双向覆盖**：论文每个数字注册溯源（结果文件→脚本→原始数据），registry 每个谓词有核对项
2. **版面门禁**：编号公式计数（模型建立每问 ≥1 条）、图型-题型匹配、表编号递增、文本卫生（双负号/占位符/乱码）
3. **要求-回应语义矩阵（M1）**：要求单元 → 章节+产出物类型；词频出现不计入。匹配纪律：产出物判定必须精确"指标名+量化上下文"，禁止宽泛正则
4. **题型交付物（M2）**：预测题必须有 MAPE/RMSE+pred-vs-actual 图；优化题必须有 Pareto 前沿/权重对比
5. **引用链+统计三要素（M4）**：[n]↔参考文献交叉验证、回归表必须有 SE/p/CI、占位符扫描、DOI 抽查
6. **数据源三态（M6）**：PASS/FAIL/UNVERIFIED 降级链

**D1 跨模态数字一致性四方 diff**：正文/表格/图内/摘要四方「指标名+数值」三元组全局 diff。
- 图内文字提取前置段 1：matplotlib 源码扫描优先，图像 OCR 兜底
- 差值→严重度映射：>5% 或单位量级错 = 致命；1–5% = 严重；<1% = 轻；同一数字多处矛盾累加升级
- 命中目标：多轮迭代论文的"新旧结果拼贴"（局部阅读抓不到，只有全局 diff 抓得到）

**D2 约束完备性枚举**（M1 的程序化前置）：按题型模板硬编码题面约束全集 → 论文公式编号/实现位置逐一映射 → 缺映射 = 「可行性声明失实」。约束全集示例（算电协同类）：GPU 容量/IT 功率/设施功率/网络时延/完工时限/MaxGridImport/MaxGridExport/SOC 上下限/SellLimit/充放电互斥/终值约束

**D3 图内文字-题注一致性**：图内自编号/标题/轴标签 ↔ 论文题注编号 ↔ 正文引用编号三方比对

**审计顺序纪律**：① fail-fast 仅用于修订-替换校验（n_replace==0 报错），审计侧穷尽执行 ② 单向棘轮：段1 finding 不可被段2 撤销；棘轮语义 = **净确认 finding 只增不减**（仲裁确认误报可标 retracted 并回溯扣分，原始记录保留）

## §二.5 视觉评审层

渲染每页 → 视觉模型四查：排版专业度 / 图表与公式密度印象 / 视觉逻辑流 / 第一印象。
**印象-事实交叉印证**：视觉报告的"数量类声称"（公式数/图表数）不可信，以脚本计数为准；落差即 finding（"看似扎实"型风险）。大图先缩略图（~1100px），关键页单独放大复查。

## §三 段2 推演与名实相符审查（E 组）

**第一步 论证链重建（评分资格前置）**：对每问重建 claim→evidence→reasoning→weak_link（sufficient/insufficient/contradictory）。无论证链无权打分。"证据在但推不出结论"是可判定缺陷。
**逻辑冲突四查**：因果方向冲突（摘要 vs 正文结论相反）/ 口径冲突（同指标两处算法不同）/ 论证冲突（推荐理由与自身数据相反）/ 循环论证。

**第二步 名实相符审查（E 组，论证链重建完成后执行）**：
- **E1 目标-机制映射**：每个题面目标必须定位"在模型哪一步生效"（公式/算法步骤/结算端）；无机制定位 = 名实不符（扣 −3）。输出"缺位判定"而非"一致性判定"。与 M3 分工：E1 查目标层，M3 查断言层（不同粒度）
- **E2 对照公平性三问**：①对照组 isolate 了声称机制？②只差一个变量？③是公平强对照（如"本地优先+统一结算"）还是弱对照（原始基准）？归因强度必须与对照公平性匹配，否则"归因夸大"（扣 −2）
- **E3 基线公允性**：领域基线先验——预测题须有季节朴素基线（滞后 24h/168h）、调度题须有 EDF 本地优先基线；弱基线 = 挑软柿子（扣 −1）
- **E4 文献评审**：数量（≥8 常模）/领域覆盖（核心方法有对应文献）/[n] 对齐/书籍·期刊·网络三式规范（扣 −0.5~−1）

**D/E 判定权威**：D 组事实层 finding 不可被 E 组推翻；E 组可对同一问题输出"语义补充"（不改事实）。

## §四 段3 定向搜索

对推演标记的疑点逐个验证：计算复现（关键数字链全链条重跑）→ 数据血缘回溯 + 错误传播反查（依赖图）→ M3 定性词-证据绑定 → 联网定向核对（失败显式报 UNVERIFIED）。每个疑点给三态结论（证实/证伪/存疑）。

## §五 段4 评分引擎（F 组，扣分记录制）

**F1 扣分记录制**：满分 100 起扣，输出"扣分记录"（finding 编号 → 扣分额），不直接给分。每条扣分必须引 finding 编号，无清单的扣分无效。
**F2 二维扣分矩阵**（严重度 × 可修复性）：

| | 易修复（文字/数字） | 难修复（需重算/重构） |
|---|---|---|
| 致命（数字打架/约束缺失） | −2~−3 | −4~−5 |
| 严重（名实不符/归因夸大） | −2 | −3 |
| 中（口径混用/基线弱） | −1 | −2 |
| 轻（写作/排版） | −0.5 | −1 |

**F3 常模分位映射**：原始分（100−Σ扣分）→ 常模分位 → 绝对分。获奖档位：一等 ≈85+、二等 75-84、三等 65-74。冷启动用公开获奖档位近似，数据积累后切实测分位。**此步骤即"相对锚点先于绝对分"的恢复点**。
**F4 证据锚定强制**：每维分数引用表号/页码/数字；无法落地引用的判无效并降档复核。
**顺序固定**：先扣分（F1/F2）→ 后映射（F3）→ F4 全程审计。原因：扣分是缺陷加和（与常模无关），映射是分数含义校准（与竞赛水位有关）。
**反锚定（机器强制）**：摘要盲评（先评摘要再读全文）、维度乱序、行为锚点五档（consistently/typically/intermittently/neglects/absent，禁止形容词脑补）。
**三评与仲裁**：GLM/Kimi/新开 DeepSeek 独立评分；总分差 >5 或维度差 >2 触发仲裁（多数/中位数 + 证据对齐）。

## §六 HARD FAIL 清单（20 条）

1. 模型建立章节零编号公式
2. 自毁性证据未回应（消融显示被平凡变体 Pareto 占优且未回答）
3. 摘要与正文因果结论相反
4. 摘要零数字
5. 定性宣称与数据形状矛盾（"平台"实为单调等）
6. 要求单元零产出物（题面点名指标无数值）
7. 点名对象缺失（题目指定分析对象未做）
8. 错误数据复用未阻断（依赖图反查）
9. 引用断裂（[n] 无对应文献）
10. 无基线（预测/优化题缺对照）
11. 数据源造假（编造数据/URL 不可达）
12. 文献编造（DOI 不存在）
13. 占位符残留
14. 摘要正文口径矛盾（同名指标两处算法不同）
15. 伪造官方口径（与题面/附件定义不符）
16. 硬编码指标伪造（AST 检测命中）
17. **约束漏建模致可行性声明失实（D2 命中，v2.6 新增）**
18. **四方 diff 致命矛盾 ≥2 处（D1 命中，v2.6 新增）**
19. **对照不公平致归因失效（E2 命中且论文无任何公平对照，v2.6 新增）**
20. 修订单无证据定位（无证据批评无效）

## §九 验收标准（6 条门槛，升级 skill 时逐条回归）

1. 离线回放：已打回论文教训命中 ≥14/17（华数杯外部 17 条基线）
2. 三评区间宽度 ≤8 分
3. 三评中位数与真人常模偏差 ≤4 分
4. v2.5 已抓缺陷零回退
5. 全流程 ≤40 分钟（超时 E 组降级：仅 E1/E2 强制、E3/E4 抽检）
6. **继承完整性回归**：保全清单 22 项每项在新版流程有定位点，缺定位点不得上线

## §十 已知边界（诚实声明）

1. D1 依赖图内文字提取质量（OCR 误差→误报，容差按图像类型校准）
2. F3 常模需历届真人评分积累，冷启动用获奖档位近似
3. E1 名实判定存在灰度（"解耦合理性"vs"目标缺位"），输出判定+理由，不强行二值化
4. 第 17 类未知缺陷仍可能穿检——靠隔离评审+校准回路持续吸收，不承诺完备
5. 三评上限受 LLM 与人类一致率约束（72-85%）：确定性层承诺零漏检，论证质量承诺可审计推理，不承诺与真人评委完全一致
