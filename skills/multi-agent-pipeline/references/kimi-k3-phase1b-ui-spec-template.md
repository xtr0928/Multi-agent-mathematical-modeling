# Kimi K3 Phase 1b UI 视觉规格输出模板

当 Phase 1b 派发 Kimi K3 做 UI/视觉架构分析时，要求其按此模板输出，确保后续 Phase 3b 审查有清晰的对比基准。

## Prompt 中嵌入此模板指令

在 Phase 1b 的 prompt 末尾追加：

```
请按以下模板输出你的 UI/视觉架构分析结果：

## 1. 页面树（层级关系）

```
首页 (/)
├── 导航栏 (全局)
├── 主内容区
│   ├── 数据面板 (3 个指标卡片)
│   └── 图表区 (折线图 + 饼图)
└── 页脚
设置页 (/settings)
├── 导航栏 (全局)
└── 表单区
```

## 2. 组件视觉规格表

| 组件 | 位置 | 尺寸 | 配色 | 状态 | 备注 |
|------|------|------|------|------|------|
| 导航栏 | 顶部固定 | 100vw × 60px | bg:#1a1a2e, text:#eee | default | 含 Logo + 菜单项 |
| 指标卡片 | 数据面板内 | 280×140px, 3列grid | bg:#16213e, border:#0f3460 | default/hover(上浮阴影) | 图标 + 数值 + 标签 |
| 提交按钮 | 表单底部 | 200×44px | bg:#e94560, text:#fff | default/hover/disabled | 圆角 8px |

## 3. 图表清单

| 图表 | 类型 | 数据源 | 标注要求 | 尺寸 |
|------|------|--------|----------|------|
| 收入趋势图 | 折线图 | GET /api/revenue | X轴:月份, Y轴:金额, 图例右上 | 800×400px |
| 用户分布 | 饼图 | GET /api/users/dist | 百分比标注, 图例右侧 | 400×400px |

## 4. UI-API 对接点

| UI 组件 | API 端点 | 请求方式 | 触发时机 |
|---------|----------|----------|----------|
| 数据面板 | GET /api/dashboard | 页面加载 | 3 个指标卡片数据 |
| 设置表单 | POST /api/settings | 点击保存 | 表单数据提交 |

## 5. 视觉一致性检查清单（供 Phase 3b 使用）

- [ ] 所有页面使用统一配色（主色/辅色/强调色一致）
- [ ] 按钮样式统一（圆角/高度/hover效果）
- [ ] 字体层级一致（h1 28px / h2 22px / body 16px）
- [ ] 卡片间距统一（grid gap 20px）
- [ ] 图表配色与整体风格协调
```
