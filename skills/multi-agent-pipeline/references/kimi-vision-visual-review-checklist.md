# Kimi K3 可视化产出审查清单

Phase 3b 使用。派发 Kimi K3 审查时，将此清单嵌入 prompt，逐项检查。

## 浏览器工具使用规范

| 工具 | 用途 | 时机 |
|------|------|------|
| `browser_navigate` | 打开页面 | 服务启动后，确认 `localhost:<port>` 可访问 |
| `browser_snapshot` | 获取页面文本结构（快速） | 检查 DOM 元素是否存在，不需视觉时优先用 |
| `browser_vision` | 截图分析（慢，有成本） | 仅 Kimi K3 视觉审查时使用 |
| `browser_console` | 查看 JS 错误/日志 | 排查前端报错时 |

**硬规则**：
- **截图前等待渲染**：`browser_navigate` 后等 1-2s 再调用 `browser_vision`，确保 CSS 动画/图表完成渲染
- **snapshot 优先**：能用文本结构判断的问题不用截图（省成本）
- **截图需对比基准**：每次视觉审查附带期望效果（来自 Kimi K3 Phase 1b 视觉规格或设计稿）

## 审查前准备

- [ ] 服务已启动，`localhost:<port>` 可访问
- [ ] 页面已完全渲染（等待 1-2s 确保 CSS 动画/图表渲染完成）
- [ ] 已通过 `browser_vision` 获取截图

## 布局审查

- [ ] 组件位置与规格一致（header/sidebar/main/footer 区域正确）
- [ ] 间距（margin/padding）符合设计稿
- [ ] 元素对齐方式正确（左对齐/居中/右对齐）
- [ ] 无明显溢出（overflow hidden 导致内容截断）
- [ ] Grid/Flex 布局在目标分辨率下正确

## 配色审查

- [ ] 主色调/辅色调/强调色与设计稿一致
- [ ] 文字与背景对比度足够（WCAG AA: ≥4.5:1 正常文本, ≥3:1 大文本）
- [ ] 链接/按钮颜色状态正确（default/hover/active/disabled）
- [ ] 暗色模式/亮色模式切换正确（如适用）

## 可读性审查

- [ ] 文字未被截断（`text-overflow: ellipsis` 是否合理使用）
- [ ] 字体大小层级正确（h1 > h2 > h3 > body）
- [ ] 中文字体渲染正常（无乱码/豆腐块）
- [ ] 表格/列表对齐可读

## 图表审查（如项目含图表）

- [ ] 图表标题存在且描述准确
- [ ] 坐标轴标签完整、不重叠
- [ ] 图例位置正确、不与数据区重叠
- [ ] 数据标注/工具提示可见
- [ ] 配色区分度足够（相邻数据系列颜色差异明显）
- [ ] 图表尺寸适配容器（不被裁剪/不空白过大）

## 交互审查（如适用）

- [ ] 按钮可点击区域足够大（≥44x44px 触摸目标）
- [ ] 表单输入框有清晰的 placeholder/label
- [ ] Loading 状态有视觉反馈
- [ ] 错误状态有提示信息
- [ ] 弹窗/Modal 居中且遮罩覆盖全屏

## 响应式审查（如适用）

- [ ] 桌面端 (1920×1080) → 布局正确
- [ ] 平板端 (768×1024) → 无横向滚动、组件换行合理
- [ ] 移动端 (375×667) → 汉堡菜单/折叠导航正常

## 输出格式

```
### 审查结果：<page_name>

| 检查项 | 状态 | 问题描述 |
|--------|------|----------|
| 布局   | ✅/⚠️ | ... |
| 配色   | ✅/⚠️ | ... |
| 可读性 | ✅/⚠️ | ... |
| 图表   | ✅/⚠️/N/A | ... |
| 交互   | ✅/⚠️/N/A | ... |

总结: ✅ 全部通过 / ⚠️ N 项需修改
```
