> 本目录是可执行管线实现。设计依据：`../docs/V5_pipeline_design.md`（v5.1）+ `../docs/V52_pipeline_design.md`（v5.2 定稿）

## 项目定位

数学建模竞赛（MCM/ICM/华数杯）72 小时解题管线的**确定性基础设施**。LLM 负责推理与写作，本目录负责**数据正确性铁律**：

1. **所有操作基于正确的数据**（用户指令 2026-08-15）：任何上游修改（数据/脚本/参数）→ 下游相关数据**全部作废重算**（工作区 manifest.json + freshness.py 强制执行：SHA-512 指纹→传递闭包 stale→拓扑序自动重跑）
2. **官方模板优先**（用户指令 2026-08-15）：S5 排版**先搜索官方模板**再动笔；TemplateGate 华数杯 10 项/MCM 6 项清单逐条核对，缺清单直接阻断
3. **篇幅达标**（用户指令 2026-08-15）：正文页数 ≥ 竞赛上限 ×75%（华数杯 20 页 → ≥15 页），LengthGate 低于即阻断；补内容=公式推导/表格/灵敏度/附录，非注水
4. **防漂移借 SHA-512**（用户指令）：三级新鲜度链，防错误数据复用，保证数据正确且唯一
5. **数值验证必须，保证所有数据可复现**（用户指令）：四断言 + 可复现性断言，每个数字可由「脚本+输入哈希+参数」重跑还原
6. **发挥算力优势**（用户指令）：C++ OpenMP 确定性重算，128 核服务器；旧进程不杀并行对照
7. **排版直观**（用户指令）：图/公式清单 + O 奖语料密度基线 + 直观性检查，排版检查交 Qwen

## 核心机制速览

### 1. 作废重算引擎（数据正确性铁律的实现）

```
param → input → script → result → claim → paragraph（六类节点 DAG）
   │        │        │
   └────────┴────────┴─ 任一哈希变化 → 传递闭包下游全部作废（禁止只标直接下游）
                          ↓
                    拓扑序重算调度（依赖先算；默认全量，增量白名单制）
                          ↓
                registry 写入门卫：旧进程按旧哈希回写 → 拒绝入库（A4）
```

- **语义化参数哈希**：改注释/键序 → 哈希不变；plot 作用域改动不触发 data/model 重算（A5）
- **原子发布**：tmp + rename；半成品文件不被认作完成（A16）
- **写回生成新版本节点**：禁止原地覆盖，DAG 永保无环（A2）
- **predicate 词汇表状态**：fresh/stale/superseded/experiment/final/non_deterministic（D27）

### 2. C++ 确定性重算（算力优势 + 可复现的铁律结合）

- **确定性三件套**：固定分块 + pairwise 归约 + counter-based RNG（splitmix64，随机流只依赖迭代序号）
- **实测**：π 估计 100 万次迭代，2/8/16 线程 × 3 次运行**逐位一致**（3.1432440000000001）
- **跨语言对照**：预生成随机数文件喂两边 + KS 分布比较；`struct.pack` 用 `=` 前缀
- **双精度纪律**：结果 JSON 用 `%.17g`，解析端逐字节恢复 double（ULP=0）
- **回退**：每 C++ 任务必须有 Python 实现，失败 ≤2 次自动回退（A11：主控停摆=0）

### 3. 假设官（假设生命周期四步）

```
生成登记 → 必要性审查 → 主动挑战（反事实+实验设计强制） → 敏感度实验 → frozen
  │            │                │（Devil's Advocate）           │（关键假设强制）
  └── 作者回避：提交者不得参与审查/挑战/判定（系统强制，A18）
```
- **隐式假设映射表**：选最小二乘自动带出「误差正态/同方差/线性」等隐式假设，漏登记即打回（A17）
- **三级分类**：关键（结论依赖→强制敏感度）/ 重要（写入 limitations）/ 边缘（仅登记）
- **防形式化**：空话挑战被拒（反事实 <10 字符 = 未挑战）

### 4. 数值验证门禁（四断言 + 可复现性断言）

随机采样代入 / 量纲维度 / 边界条件（≥3 组）/ sympy 符号比对 + **可复现性断言**（同输入重跑 3 次哈希全等且与注册值一致）。挂 build 钩子，移除全部 Agent 后门禁仍可执行（A32）。

### 5. 双状态机（断点恢复 × 72h 时间窗）

- **进度状态机 = 唯一事实源**：checkpoint + append-only 变更日志；恢复第一步重放日志重建 dirty 全集，**完成标记一律不信，只信任哈希匹配的产物**（A13）
- **时间窗状态机只读不拥有**：商议 14% / 双轨迹 42% / 成文 25% 硬保底 / 纠错 ≤20%；预授权降级清单（重算挤占成文 >30% → 自动双轨迹转单轨迹等，不等用户确认）
- **铁律优先级**：正确性 > 完整性 > 时间窗

### 6. 排版层（直观性）

- **图清单**：六要素登记（含 data_source_hash——数据作废→图条目 dirty→门禁阻断）；info_gain 防 chart junk；孤儿图阻断（A22）
- **公式清单**：编号连续 + 引用完整，孤儿公式 blocking
- **密度标准**：O 奖语料 IQR 基线（默认先验：12 页 8-14 图 / 15 页 10-18 图；公式按题型分档）
- **直观性**：枚举化规则检查（轴标签/图例/单位/字号/子图上限）+ Qwen 视觉官 3 秒理解度（LLM 部分，由管线编排时调用）

## 铁律（本目录所有代码遵守）

**v5.2 六条（最高优先级）**：① 定稿即法律——S1.5 定稿是唯一真源，后续阶段不得自创方法/参数/口径 ② 单一责任人——每问求解、每个数字、每段正文有且仅有一个责任人 ③ 数字唯一入口——论文数字只从 registry 注入，writer 禁止生成数字/文献/声明 ④ 修一处→全链重做（freshness 含定稿节点） ⑤ 产物分数进门禁——不过 S7 不出管线 ⑥ 零上下文隔离——参谋/拍板/四评/写作各实例互不带上下文（防路径固执与污染）。

**v5.2.1 四条（2026-08-16 华数杯 C 四轮评审教训，堵"定稿时拍板、实现时打折"）**：
⑦ **实现-定稿比对门禁（S2.5）**——求解完成后 `impl_manifest.json` 逐条声明每个 D-决策的实现架构；与定稿不一致且未引用兜底条款编号 = 阻断（作废重做协议）。降级必须走决策日志，禁止静默打折。
⑧ **装配层归因纪律（R1-R6）**——对照表→结论直接导出（禁止反向圆说）；头条结论与结构性前提同级呈现；定义恒等式禁止包装为命题；可疑精确结果必须附机制；方法对比必须含数据形状适配基线。
⑨ **决策核心适配论证**——参谋提交方案前必须回答「数据形状→建模粒度」与「数据字典条款→模型口径映射」两项论证，缺一废票；拍板者定稿必须含口径条款清单与兜底协议编号。
⑩ **评审 v2.9 四审计**——评委 skill 新增 D4 声明强度 / D5 可疑精确性 / M7 MCDA 稳健性 / M8 基线完备性（`skills/data-science/mathmodel-judge-perspective/`）。

**既有铁律**：写评分离 · 评审零上下文隔离 · 作者回避 · 确定性门禁不认模型挂 build 钩子 · 72h 时间窗成文 25% 硬保底 · 旧进程不杀并行对照 · T5 窗口内权重 0 · 正确性 > 完整性 > 时间窗
