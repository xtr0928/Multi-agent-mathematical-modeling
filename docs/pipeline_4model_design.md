## Part A. 混合编码管线更新：视觉全 Qwen 化 + K3 收缩

### A1 视觉任务硬路由（全 Qwen，无例外）

路由层硬编码以下任务 → Qwen 视觉官（vision_analyze 已切 custom/qwen3.8-max/DashScope compatible-mode，2026-08-14 落地）：

| 视觉职责 | 说明 |
|---|---|
| vision_analyze 视觉核查 | 架构图/图表/页面逐块分析（已切换，实测质量达标） |
| UI 设计 | 页面/图表设计迭代 |
| 图表渲染检查 | 渲染 PDF/PNG 像素级检查（缺字体/豆腐块/空图/线重叠） |
| OCR | 扫描件/图内文字提取 |
| 页面验收 | 交付物视觉验收 |
| 图内文字提取（D 组前置） | 评委 v2.6 D 组「图内文字-题注一致性」的前置输入，提取结果进确定性 diff 管线 |

**硬约束 AC-K3：K3 视觉调用 = 0**（30 天全链路日志审计验证）。K3 在编码管线剩余职责仅一项：**低频高价值推理审查**（设计审查先行，如本次）。K3 不可用时降级为 GLM 架构评审扩展（标注降级）。

### A2 视觉单点共模防护（Kimi 审查核心新增）

K3 视觉零调用后，视觉链只剩 Qwen 一家——且 Qwen 同时是图的生产者（T3 编码画图）与检查者（视觉官）。错误不是「被漏检」而是可能「被确认无误」。三道防线：

1. **OCR 双读取头**：Qwen vision + 非 LLM 传统 OCR（PaddleOCR）。关键字段（图内数字/标题）两读不一致 → 升级人工/重渲染。
2. **程序化渲染断言（零 LLM）**：字体嵌入检查、像素非空率、文字区域检测——豆腐块/空图这类错误不经过任何模型判断。
3. **种子缺陷图注入回归**：已知缺陷图库（缺字体/标注重叠/数字矛盾）注入视觉检查，漏报即阻断。与检测层种子库同构。

### A3 角色矩阵（混合编码管线）

| 角色 | 模型 | 变化 |
|---|---|---|
| 编排/主献策/失败接管 | DeepSeek V4 Pro | 不变 |
| T1/T2 快速编码 | kimi-coder (K2.7) | 不变 |
| T3 长任务编码 | qwen-coder (Qwen3.8-Max) | 不变（准入三测已过） |
| 架构评审 | GLM 5.3 | 不变 |
| 视觉官（视觉/UI/OCR/渲染检查/页面验收） | Qwen3.8-Max | **全权（K3 视觉彻底退役）** |
| 推理审查 | Kimi K3 | **收缩至仅此一项，视觉零调用** |

## Part B. 数模管线四模型化：Qwen 第四全权模型

### B1 Stage 2 商议四向化（建模手 ×4）

- 四方独立深推（DS/GLM/K3/Qwen 零上下文实例并行）→ 交换批评 → 各自修订，2–3 轮自然停止，**分歧不强制收敛**。
- **2v2 僵局出口（Kimi 场景 4）**：四方偶数票，天然存在 2v2。规则：**2v2 = 分簇即轨迹**，两条路线直接映射为双轨迹 A/B 各领一条，无需收敛。时间闸门兜底：商议到 14% 上限强制切换。
- 时间预算：四实例并行，墙钟时间与三方相当；验收线 = 商议中位 ≤8.6h（12%）、p90 ≤10h（14%）。

### B2 检测层四向化（抽取 ×4）

- 四方独立抽取全文声明取并集（并集召回率单调 ≥ 三方基线）；producer 标签过滤（Qwen 不抽 Qwen 自产工件）；种子库注入回归照旧，召回率硬指标按模型分层统计。
- **回退**：Qwen 抽取召回率低于硬指标 → 该轮其抽取结果标记不可信，以三方并集为准，Qwen 检测实例重跑种子库回归。

### B3 Stage 4 评审四向化 + 仲裁规则修订

- DS/GLM/K3 全权 + Qwen 按阶梯状态参与（影子→灰度→转正，见 Part C）。
- LLM 只做相对排序，不做绝对打分（铁律保留）。
- **四票仲裁三规则修订（Kimi E3）**：
  - 极差 ≤5 取均值 / 孤立值差 >8 触发审查 / 两两分簇差 >5 深度仲裁——三规则阈值按三票分布设定，四票下孤立值/极差概率结构性上升 → **转正前须 ≥10 场历史回放重校准阈值**。
  - **2v2 出口**：2v2 且簇间差 >5 → tie-break：GLM/DS 一族加开零上下文第二实例，或回退三家族多数；**禁止无限深度仲裁**。
  - **仲裁次数预算**：深度仲裁 ≤2 次/场，超出降级为取中位数快速规则。

### B4 评委终评四评（v2.6 链扩展）

- 评委终评链 = GLM/K3/DS（零撰写上下文）三评 + Qwen 第 4 评（阶梯）。
- **分位映射重算（Kimi E5）**：v2.6 扣分记录制 + 分位映射基于三评分布拟合；第 4 评入链后分布形状改变——Qwen 转正后须用影子期积累的四评分布**重新拟合分位表**，禁止直接套用旧映射。扣分项清单需确认对 Qwen 失效模式的覆盖（其幻觉模式与 GLM/Kimi 不同族）。
- **同源偏移检测（Kimi E4，全新机制）**：producer 标签过滤只解决「知情的自评」，不解决「不知情的同源偏差」（Qwen 训练分布系统性偏向 Qwen 产出物）。影子期与灰度期按工件 producer 分层统计 Qwen 票偏移：|Δ| > 3 → 触发降权，而非仅个案仲裁。转正条件含：Qwen 票对自产 vs 他产工件的评分偏移 |Δ| ≤ 2 且统计不显著。

### B5 四视角边际收益不默认成立（诚实度量）

「多一个模型多一份视角」是期望不是事实。验收附加度量：检测层并集召回率增益 vs 三方基线；商议中 Qwen 提案被采纳的贡献计数。若边际收益显著低于预期，如实报告并评估「Qwen 建模手保留 or 降为替补」——**不为多样性而多样性**。

## Part C. 校准阶梯 v2（Qwen 打分类角色准入，重构自既有四评设计）

既有四评设计（影子 ≥15 轮 / 灰度 5 轮 / 转正）的三个数值本身（±8 / ±3 / 80%）沿用，**达到数值的过程**全部重构：

| 维度 | 既有设计 | v2 修订（Kimi E1/E2 采纳） |
|---|---|---|
| 轮次定义 | 15 轮（未定义 1 轮 = 什么） | **有效轮次**：实战 Stage 4 = 1.0 轮；历史回放 = 0.5 轮且须过训练集污染审计（旧题在 Qwen 训练语料内概率不可忽略） |
| 版本 | 未 pin | **pin 快照 + 逐次记录 actual version**；版本变更 → 已有轮次清零或按 0.5 折算（alias 漂移会让影子数据前后来自混合分布） |
| 日历上限 | 无 | **6 个月**。到期未达标 → 0.3 权重降级使用（不放水转正）；可重新走完整阶梯 |
| 灰度权重 | 0.5 权重直接参与 | **双层用法**：三规则检测逻辑一律用原始分（加权分会把孤立值压扁到阈值以下，检测失灵）；0.5 权重仅用于最终分数合成；灰度票在分簇判定中先剔除再判（半票不参与制造 2v2） |
| 状态机 | shadow→gray→full | shadow→gray（有效轮次≥15 且偏差达标且版本稳定）→full（灰度 5 轮一致性 ≥80% 且同源偏移 |Δ|≤2）→ 漂移退回 gray（连续 3 轮偏差 >±8 或 |Δ|>3）；gray 一致性 <60% → 退回 shadow |

## Part D. 风控与回退状态机

### D1 Qwen 多身份隔离（升级为运维级）

Qwen 六身份（**coder / vision / 建模手 / 检测抽取 / Stage4 评审 / 评委**）零上下文互不相见。**工程实现约束**：

- 每身份独立 API 子账户（DashScope 子账户；平台不支持则退化为 role 标签 + 分账日志 + 限流预留），账单按身份可拆分——同 key 的「隔离」在日志层不可观测、不可验收。
- 每次调用强制 role 元数据落日志；工程失败（429/超时）与质量失败分账，**工程失败不进校准统计**（防限流噪声污染影子期数据）。
- 配置分文件管理（系统提示词/温度/上下文），CI lint 禁止跨身份引用同一配置。

### D2 producer 标签（内嵌，非 sidecar）

- 标签内嵌工件 frontmatter，与内容同生命周期（sidecar 模式在格式转换/人工粘贴环节必然丢失）。
- 入库门禁：无 producer 标签拒收。hash 注册表反查：无标签工件按内容指纹找回 producer。
- 评审/检测分发前校验 producer 模型族 ≠ 评审模型族。

### D3 回退状态机（全部预定义，禁止现场决策）

| 位置 | 触发 | 动作 |
|---|---|---|
| 编码位（已有） | 门禁失败 ≤2 次 | DS 接管重写；旧进程不杀并行对照 |
| Qwen 建模手（新） | 门禁打回 2 次 | 降权 0.5 + 商议轮次 -1 |
| | 打回 4 次 | 暂停：观察员模式（只接收批评不产出路线）；路线份额由双轨迹兜底 |
| | 连续 3 轮通过 | 恢复全权 |
| Qwen 评审（新） | 转正后连续 3 轮偏差 >±8 或同源偏移 >3 | 退回灰度 |
| | 灰度一致性 <60% | 退回影子 |
| Qwen 检测（新） | 种子库召回率低于硬指标 | 该轮标记不可信，三方并集为准 + 重跑回归 |
| 视觉官（新） | 失败 | Qwen 重试 ≤2 次 → 人工介入（K3 视觉零调用 = 视觉无模型回退，这是成本指令的显式代价） |
| 时间闸（新） | 商议达 14% 上限 | 强制切换双轨迹，2v2 按分簇即轨迹 |
| | Stage 4 结束时剩余 <18h | 冻结一切新仲裁/纠错任务（成文 25% 硬保底的闸门机制） |

## Part E. 成本预算

- **目标（可测）**：四模型化后单场总成本 ≤ 原基线（三模型 + K3 视觉）×90%——K3 视觉退役省下的钱必须大于 Qwen 新增角色 + 影子期沉没成本，否则「K3 太贵」的原始指令未达成。
- Qwen 各身份单价约束沿用准入线：T3 编码 ≤ DS×1.5；视觉/OCR 走 DashScope 计费（远低于 K3 视觉计费）。
- ⚠️ **未验证数据声明**：GLM 骨架中「K3 单价约为 Qwen 的 8–12 倍」为模型自报估计，**无实测账单依据，不进入任何结论**；以首战实测账单为准。
- 影子期成本 = 只记录不仲裁，可控；灰度期 0.5 权重。
- **二期收缩路线图（本期不做，仅记录）**：四模型化转正后若 K3 成本仍超预算，可评估「数模建模手 K3 → Qwen 双实例」替换（同源问题由同源偏移检测兜底）。用户本期指令是「加 Qwen 不减 K3」，故 K3 数模位本期保留全权。
