# 评委 Skill v2.5 更新方案（混合编码管线定稿）

> 编排：DeepSeek V4 Pro（本会话）| 架构分析：GLM 5.3 | 内容审查：Kimi K3
> 生成时间：2026-08-13 | 输入：v2.4 全文 + 两轮外部打回教训全集（MCM 66-70 / 华数杯 56-65）

## 一、核心洞察

GLM："评审系统需从基于规则的静态检查转向基于学习的动态适应。"方向正确，但其"砍掉七维评分/静态 HARD FAIL"的建议**不采纳**——它们是 437 篇实证校准的核心资产，问题不在资产本身而在资产与论文之间的"映射层"太薄：
v2.4 的机制查"数字同值、名词出现、公式存在"，但**不查"要求是否被完成"**——词频出现≠完成回答（Q3 峰值净购电被提及但无任何数值）、数字同值≠因果一致（摘要正文数字都改对了但因果结论相反）、公式存在≠模型可读（零公式是 v2.4 才补的门禁）。

**v2.5 的主干 = 把检查对象从"字面"升级为"语义完成度"**：要求单元→产出物映射、定性词→证据绑定、题型→交付物清单、双评→锚定抗性。

## 二、v2.5 六项机制（采纳 Kimi 5 条 + GLM 一致性 1 条）

### M1 要求-回应语义对照矩阵（根治 A1 舞者漏做 / B4 峰值漏答）
- 题目原文提取"要求单元"= 实体名词 + 量化指标 + 限定词（整季/全程/指定案例名单）+ 交付动作（分析/给出/比较）
- 每个要求单元必须映射到：论文章节 + 产出物类型（公式/表/图/具体数字），词频出现不计入覆盖
- 无产出物映射 = 漏答（major 起步）；有提及但产出物类型错配（要求"分析影响"只给文字叙述）= 部分回答

### M2 题型-交付物强制清单（根治 B5 无基线 / B8 无 Pareto / A7 推荐无解释）
- 段1 先判题型：预测 / 优化 / 评价 / 机理 / 统计
- 题型必备交付物：预测→MAPE/RMSE+pred-vs-actual 图+残差诊断；优化→Pareto 前沿图+权重方案对比表；评价→指标体系+权重敏感性；机理→参数标定+量纲分析
- 缺必备交付物 = 该维度封顶

### M3 定性宣称-证据绑定扫描（根治 A7"平台"实为单调 / B8"解耦"与数据不符）
- 定性词清单：平台/饱和/拐点/解耦/主导/显著/协同/权衡/鲁棒
- 每个定性词必须有证据定位（具体图/表/数字编号）；无证据 = major
- **与数据形状矛盾（宣称"平台"而曲线单调、宣称"解耦"而数值变化超过容差）= HARD FAIL**

### M4 引用链与统计报告完整性（根治 A5 引用断裂 / A8 无标准误+占位符）
- 正文 [n] ↔ 参考文献列表交叉验证：编号连续、无悬空引用、每引用有对应条目
- DOI/URL 联网抽查可达性（与 v2.4 联网机制合并）
- 回归/统计表强制三要素：SE / p 值 / CI（缺一即 major）
- 占位符与模板残留扫描：Page X of Y、Team #、TODO、XX、页眉残留

### M5 评审反锚定与重测稳定（针对自评 86 vs 外部 66-70 的评分漂移）
- **同文双评**：两个独立子代理分别评分；总分差 >5 或任一维度差 >2 → 触发第三评仲裁
- 维度乱序评分 + 摘要单独盲评（先评摘要再读全文，防止全文印象反向污染摘要分）
- 相对锚点（437 篇基准分位）先于绝对分输出
- 两轮自评分数漂移 >3 分 → 禁止对外报告自评分数，只报区间

### M6 数据源与口径联网核查扩展（v2.4 机制二强化 + 冷启动重设计）
- 数据源 URL/DOI 可达性抽查（不只是数字口径）
- 数据集三要素强制：名称 + 版本 + 获取日期
- 预处理链条合理性核对（原始样本量 → 清洗后样本量的变化可解释）

**M6 冷启动重设计（评审参照系分层，时序加权）**：
竞赛真实场景是刚开赛——3 天赛程内网上无同题论文、无获奖范文、无标准答案。联网核查因此必须按"参照系分层"设计，不依赖同题信息：

| 层 | 内容 | 用途 | 刚开赛可用 |
|----|------|------|:---:|
| T1 官方规范 | 题目原文/格式规范/AI 章程 | 合规基准（名词对照、格式门禁输入） | 永远 |
| T2 历史水平标尺 | 往年同题型 O/M 奖论文（本地 437 篇 + 线上延伸） | "这类题做到什么程度算好"的评分锚 | 永远 |
| T3 领域知识 | 题目背景行业资料（如算电协同政策、区域碳强度参考、峰谷电价机制） | 评审"数字是否离谱、口径是否行业标准" | 永远 |
| T4 方法论标准 | 预测/优化/储能的教科书级做法与评价指标规范 | 评审"方法是否常规、指标是否用对" | 永远 |
| T5 同题信息 | 赛后才出现的思路/论文/获奖名单 | 仅作水平标尺参考，按赛程时间加权（刚开赛权重 0） | 赛程中无 |

铁律：① 评审的锚 = 题目要求 + 领域标准 + 历史水平，不依赖同题信息——两轮打回暴露的问题（零公式/因果矛盾/指标漏答）无一需要同题信息才能发现；② 同题信息永不作正确答案来源（赛程中的"思路"错误率极高，防污染），只作他人做法分布参考且标注来源时效。

## 三、保留与不采纳

**保留 v2.4 全部机制**：评审智能体隔离（delegate_task 新开子代理）、联网核查、版面公式门禁（编号公式计数/图质量/表序/文本卫生/三方数字比对）、自毁性证据 HARD FAIL、替换校验纪律、七维评分+相对锚点、修订单 JSON、量化收敛、写评分离。

**不采纳 GLM 的砍单**（记录理由）：
- 砍"简单数字索引检查"→ 不砍：确定性检查的零误报价值不可替代，只增强不替代
- 砍"静态 HARD FAIL 清单"→ 不砍：实证校准的锚点资产，改为"清单 + 动态缺陷检测"并行
- 砍"固定七维评分"→ 不砍：统一维度是相对锚点可比性的前提
- 砍"简单替换校验"→ 不砍：fail-fast 纪律继续保留

## 四、v2.5 执行形态（两段式不变，段1 扩充）

```
段 1 确定性审计（脚本 + 联网）：
  ① 数字索引 registry 双向覆盖
  ② 要求-回应语义矩阵（M1）——题型判定（M2）加载交付物清单
  ③ 版面门禁：编号公式/图型-题型匹配/表序/文本卫生（含占位符扫描）
  ④ 引用链交叉验证 + DOI 抽查（M4）
  ⑤ 定性词-证据绑定（M3，语义层）
  ⑥ 复现抽查
段 2 隔离评审（两个独立子代理，M5 双评）：
  子代理 A / B 各自：读 PDF 原件 + 联网核题 → 七维评分 + 修订单
  分歧 > 阈值 → 第三评仲裁；结论 = 分数区间 + 相对锚点 + 修订单
```

## 五、验证方式（v2.5 自身也要被验证）

- 用两轮已打回论文（MCM 26C、华数杯 26C）做**回放测试**：v2.5 机制能否在门禁通过状态下复现外部评审的致命问题（回放命中率目标：16 条教训命中 ≥ 14）
- 用 437 篇基准中的已知档位样本做评分漂移测试（双评差分布）
