六条铁律（落位于 PROJECT.md 与各门禁）

  • 定稿即法律——S1.5 定稿是唯一真源，后续阶段不得自创方法/参数/口径
  • 单一责任人——每问求解、每个数字、每段正文有且仅有一个责任人
  • 数字唯一入口——论文数字只从 registry 注入，writer 禁止生成数字/文献/声明
  • 修一处 → 全链重做——freshness 作废重算（含定稿节点）
  • 产物分数进门禁——不过 S7 不出管线
  • 零上下文隔离——参谋 / 拍板 / 四评 / 写作各实例互不带上下文（防路径固执与污染）
