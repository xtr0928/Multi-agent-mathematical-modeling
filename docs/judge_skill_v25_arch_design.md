## 一、定稿骨架（GLM 12 模块 + Kimi 5 处修正）

### 状态机（Kimi 陷阱 4 修正：审计穷尽无短路，fail-fast 仅限修订回路）

```
[论文 PDF + 题目文件]
  → 段1 确定性审计（六子检查穷尽执行，finding 独立记录，互不遮蔽）
     ①数字 registry ②M1 语义矩阵 ③M2 交付物 ④M3 定性词 ⑤M4 引用链 ⑥版面门禁
  → 段1 finding 单向棘轮（段2 只能确认/追加，永远不可撤销）
  → 段2 隔离双评（A≠B 模型，摘要盲评+维度乱序，机器强制非 LLM 自觉）
  → 分歧 > 阈值 → 第三评仲裁
  → 输出：分数区间 + 相对分位 + 修订单（Top-12，evidence 强制）
  → 修订回路：修订单回喂 → **全量重跑段1+段2**（禁止针对性复查，陷阱 5）
  → 收敛：Δ分数 <1 或 2 轮无 critical → 交付
  → 漂移监控：修订前后分数差入库；对外只报区间
```

### 校准回路（每轮外部打回）

```
外部打回分数 → 二分闭环（Kimi：覆盖缺口 vs 尺度偏差分别归属不同修复路径）
  覆盖缺口（该查没查）→ 补 M1-M4 规则 + 教训-机制映射更新
  尺度偏差（查了但给宽）→ ScoreCalibrator 锚点更新 + 偏差修正项
  → 回归测试用例入库 → 回放重测（16 条教训命中 ≥14 才放行）
```

### 冷启动五层参照系（M6 重设计，落地为模块 8 的输入）

T1 官方规范/T2 历史标尺/T4 方法论标准：**赛前全量本地化**，评分锚零网络可用
T3 领域知识：联网增强，降级链（在线→本地缓存→UNVERIFIED 标注）
T5 同题信息：竞赛窗口内权重=0（时钟硬门控非 LLM 裁量），命中即隔离打标，永不作评分依据

### 边界（GLM 5 条全采纳）

不依赖同题信息作正确答案 / 不创作改写论文 / 不替代人工终审 / 不跨题型泛评 / 不出题

## 二、Kimi 8 条验收标准（架构必须通过）

1. **离线回放完备性**：断网跑 MCM 26C + 华数杯 26C，16 条教训命中 ≥14，HARD FAIL 类 100% 离线可命中
2. **穷尽无短路**：注入 ≥5 条并发缺陷，报告 finding 数 ≥ 注入数
3. **单向棘轮断言**：自动化检查段2 输出，无任何段1 HARD FAIL 被撤销
4. **双评效度**：437 篇已知档位样本，双评总分差>5 比例 ≤ 阈值，仲裁正确激活
5. **污染免疫**：伪造"官方思路"注入检索，评分偏移 ≤ 噪声阈值，T5 标注完整
6. **降级诚实**：kill-network 测试无静默绿，全部跳过项列出+置信度降档
7. **输出协议合规**：分数区间+相对分位+修订单三段结构，漂移>3 无点分
8. **校准闭环时效**：外部打回 → 映射更新+用例入库 → 回放通过，一个迭代周期内

## 三、Kimi 5 陷阱的对策（已并入模块设计）

| 陷阱 | 对策 |
|------|------|
| M1-M3 过拟合 16 条教训 → 第 17 类缺陷穿检 | 规则抽象到"要求单元-交付物类型"层级；留 3 条教训 hold-out 做泛化测试 |
| 双评假独立（同模型误差强相关） | 模块 9：A/B 强制不同模型；周期性外部评分再锚 |
| 历史锚点固化偏差 | 模块 11：锚点按题型分层 + 外部打回再校准 |
| fail-fast 误用域蔓延 | 状态机：审计穷尽、fail-fast 仅限修订-替换校验 |
| 修订回路刷分 | 修订后全量重跑+重新双评+分数差入漂移监控 |
